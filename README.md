# Sales Performance Dashboard Using Power BI

## Project Overview

This project focuses on analyzing sales performance and creating an interactive dashboard using Microsoft Power BI.

The dashboard provides insights into total sales, profit, order performance, product categories, and city-wise sales. It helps users understand business performance through interactive visualizations and reports.

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Modeling

## Project Objectives

- Analyze overall sales and profit performance.
- Monitor key business performance indicators (KPIs).
- Compare sales across different cities.
- Analyze category-wise sales performance.
- Identify sales trends and business patterns.
- Create an interactive dashboard for business reporting.

## Dashboard KPIs

1. Total Sales
2. Total Profit
3. Total Orders
4. Delivered Orders
5. Cancelled Orders

## Dashboard Visualizations

1. **KPI Cards** – Display important business metrics such as total sales, profit, and order counts.
2. **City-wise Sales Analysis** – Compare sales performance across different cities.
3. **Category-wise Sales Analysis** – Analyze revenue generated by product categories.
4. **Order Status Analysis** – Understand delivered and cancelled order distribution.
5. **Payment Method Analysis** – Compare orders across different payment methods.
6. **Sales Performance Charts** – Present key sales insights through interactive charts.

## Key Business Insights

- Compared sales performance across Delhi, Hyderabad, and Noida.
- Identified Furniture as the highest-revenue product category.
- Evaluated order status distribution.
- Analyzed payment method preferences.
- Compared sales and profit performance across categories.

## Project Objective

The main objective of this project is to develop practical Power BI skills and demonstrate the ability to transform sales data into interactive dashboards that support business decision-making.
